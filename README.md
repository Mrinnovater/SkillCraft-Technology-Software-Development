# 🔢 Guess Game - Flask Edition

A fun and interactive number guessing game built with **Python**, **Flask**, and deployed on **Render**. The user attempts to guess a randomly generated number — a classic game with a clean UI and fast backend logic.

## 🚀 Live Demo
🔗 [Play Now](https://guess-gamess.onrender.com/)

---

## 📦 Tech Stack

- 🐍 Python 3
- 🔥 Flask (backend)
- 🧠 Gunicorn (production server)
- 🌐 HTML/CSS (frontend)
- ☁️ Render (cloud deployment)

---

## 🎮 How to Play

1. Enter a number between 1 and 30.
2. Receive instant feedback: whether guess correct or wrong!
3. Try again until you guess the correct number within the 3chances.

# 🌡️ Temperature Converter Web Application

---

This is a simple web application that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin. It is deployed and hosted on Render.

## 🚀 Features
- 🔄 Convert between Celsius, Fahrenheit, and Kelvin.
- 🖥️ User-friendly interface.
- ⚡ Instant temperature conversion.
---
## 🛠️ How to Use
1. 🌐 Go to the deployed website: [Temperature Converter](https://temperature-converter-d0yz.onrender.com/)
2. 🔢 Select the temperature scale you want to convert from.
3. ✍️ Enter the temperature value.
4. 🔄 Choose the temperature scale you want to convert to.
5. ✅ Click "Convert" to see the result.
---
## 💻 Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python
- **Hosting**: Render
